# RDPShell

This small application allows you to setup a windows user that launches directly into an RDP session on a remote PC.

## Download
- [Standalone EXE (no runtime needed)](https://github.com/GitKDF/RDPShell/releases/latest)
  - Requires [.NET 8 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/latest/runtime)
